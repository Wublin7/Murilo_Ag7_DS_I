# 💧 Consumo de Água

## 🎯 Objetivo

O **Consumo de Água** é um sistema desenvolvido para classificar o consumo mensal de água de imóveis e apresentar mensagens educativas de conscientização ambiental. 🌱💧

## 🐍 Linguagem utilizada

O projeto foi desenvolvido em **Python 3**.

## ▶️ Como executar

1. Instale o **Python 3**.
2. Baixe ou clone este repositório.
3. Abra a pasta `consumo-agua`.
4. Execute o arquivo `app.py` pelo terminal:

```bash
python app.py
```

## 💧 Funcionamento

O programa solicita o **tipo de imóvel** e o **consumo mensal de água em m³**. Em seguida, classifica o consumo de acordo com as regras definidas e apresenta um alerta ao usuário.
